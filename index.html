2. Dán voucher

Cách lấy voucher

  1. Mở sepolia.squeekchain.com/mint, đăng nhập bằng đúng ví nhận, bấm Get claim authorization.
  2. Voucher là phản hồi của POST https://community.squeekchain.com/v1/community/mint/authorization (hoặc trường authorization trong GET .../v1/community/mint/status). Trên máy tính: DevTools → Network → chọn request authorization → Response → copy JSON dán vào đây (dán nguyên JSON cũng được, trang tự tìm các trường).
  3. Hoặc trên máy tính, ở tab squeekchain mở Console và chạy:
    fetch('https://community.squeekchain.com/v1/community/mint/status',{headers:{authorization:'Bearer '+JSON.parse(localStorage['squeek.community.session']).token}}).then(r=>r.json()).then(d=>console.log(JSON.stringify(d.authorization)))

Trang này không thể tự lấy voucher: API chỉ cho phép trang squeekchain gọi (CORS) và cần token đăng nhập của bạn. Voucher có hạn ngắn, lấy xong dán ngay.
